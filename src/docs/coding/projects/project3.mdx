# 📊 数据可视化平台

为西南石油大学打造的专业数据可视化平台，帮助师生更好地理解和分析各类数据，支持科研和教学需求。

## 🎯 项目目标

- **数据驱动**: 将复杂数据转化为直观的可视化图表
- **教学辅助**: 为各专业课程提供数据展示工具
- **科研支持**: 支持科研数据的可视化分析和展示
- **跨平台**: 支持Web端和移动端数据展示

## 🚀 核心功能

### 可视化类型

| 图表类型       | 适用场景               | 技术实现           | 难度     |
| -------------- | ---------------------- | ------------------ | -------- |
| **基础图表**   | 数据趋势分析           | ECharts, Chart.js  | ⭐⭐     |
| **地理信息**   | 空间数据展示           | Mapbox, Leaflet    | ⭐⭐⭐   |
| **3D可视化**   | 三维数据建模           | Three.js, D3.js    | ⭐⭐⭐⭐ |
| **交互式图表** | 动态数据探索           | Vega-Lite, Plotly  | ⭐⭐⭐   |
| **专业图表**   | 石油工程专业数据       | 专业可视化库       | ⭐⭐⭐⭐⭐ |

### 数据源支持

- **文件上传**: CSV, Excel, JSON 格式支持
- **数据库连接**: MySQL, PostgreSQL, MongoDB
- **API接口**: RESTful API 数据接入
- **实时数据**: WebSocket 实时数据流

## 🏗️ 技术架构

### 前端技术栈

- **框架**: React + TypeScript
- **可视化库**: ECharts, D3.js, Three.js
- **样式**: TailwindCSS + CSS Modules
- **状态管理**: Zustand
- **构建工具**: Vite

### 后端技术栈

- **语言**: Node.js + Python
- **框架**: Express + FastAPI
- **数据库**: PostgreSQL + Redis
- **数据处理**: Pandas, NumPy
- **部署**: Docker + Nginx

### 数据服务

- **数据清洗**: 自动化数据预处理
- **缓存策略**: Redis 数据缓存优化
- **权限控制**: 数据访问权限管理
- **性能监控**: 可视化渲染性能监控
